# AGENTS.md - Project Commands

## Python
- Portable Python: `C:\MCP\python\python.exe`
- Для установки пакетов используй портабельный питон: `C:\MCP\python\python.exe -m pip install <package>`
- Системный pip НЕ использовать — ставь только в портабельный

## Running
- `start.bat` or `run.bat` to launch the companion
- MCP Server: `http://127.0.0.1:8765/mcp`
- Web UI: `http://127.0.0.1:8766`
